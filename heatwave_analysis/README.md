# ERA5 热浪月平均百分位异常分析（4-6 月 Tmax/Tmin，1979-2026）

**目的**：分析 2026 年 4-6 月北半球每日最高温（Tmax）与最低温（Tmin）月平均的
气温异常与百分位异常，聚焦 **2026 年 6 月欧洲严重热浪**及其**夜间高温**特征，
为论文提供定量分析与图件。

**产出**：每月一张（共 6 张）的月平均异常图 / 百分位图 + 欧洲关注区统计表。

---

## 1. 方法与数据

| 步骤 | 说明 |
|------|------|
| 数据 | ERA5 小时级 2m 气温（`t2m`），1979-2026 年 4-6 月 |
| 日极值 | 逐日 `max(t2m)` → Tmax，`min(t2m)` → Tmin（UTC 日界） |
| 月平均 | 逐月对日极值取平均 |
| 气候态 | 默认 1979-2026 各月多年平均（与你的原方法一致） |
| 异常 | 2026 年月均值 − 气候态（单位 K） |
| 百分位 | 2026 年月均值在 1979-2026 全部年份中的位置（0-100%） |
| 图件 | 每月一张，3 行（4/5/6 月）× 2 列（Tmax/Tmin） |
| 叠加 | 黑色等值线 = 90 百分位（1979-2026） |

> ⚠️ **方法学提醒（写论文时注意）**
> 1. **趋势问题**：1979-2026 气候态包含变暖趋势，会"稀释"2026 年的相对极端性。
>    建议额外用 `--clim 1979-2000` 跑一遍做对照，说明"在旧气候态下这些异常更极端"。
> 2. **月平均稀释**：6 月热浪集中在 6 月 19-30 日，月平均会摊薄事件强度。
>    建议补充热浪日数、累积强度（超阈值 Tmax/Tmin 之和）、逐日百分位分析。
> 3. **ERA5 vs 站点**：ERA5 日极值略低估站点观测极值（尤其伊比利亚高原、阿尔卑斯等
>    复杂地形），与观测对比时注意方向。

## 2. 运行

```bash
# 环境（需要 Python ≥3.10）
pip install xarray netCDF4 matplotlib cartopy shapely

# 1) 演示模式（无数据也能跑，验证流程；使用合成数据，2026年含西欧热浪信号）
python analyze_era5.py --demo --outdir output

# 2) 真实数据：data/ 目录放小时级 t2m 的 NetCDF（可多个文件，如 CDS 按年/月下载）
python analyze_era5.py --data /path/to/era5_hourly --outdir output

# 3) 欧洲放大图 + 旧气候态对照
python analyze_era5.py --data /path/to/era5_hourly --region europe --clim 1979-2000 --outdir output_oldclim
```

## 4. 2026 年 6 月热浪官方参考值（Copernicus/ECMWF，可用来核对你自己的图）

| 指标 | 数值 |
|------|------|
| 全球 2026-06 | 第二暖 6 月（ERA5：16.54°C，+0.56°C），仅次于 2024 |
| 欧洲陆地 2026-06 | 第二暖 6 月（19.14°C，+1.78°C），仅次于 2019 |
| **西欧**（11°W-15°E, 37-55°N） | **有记录以来最暖 6 月**：20.74°C，**+3.06°C** |
| 月均异常最大区 | 法国、德国、西班牙、意大利、比荷卢：**+3~5°C** |
| 超过 90 百分位（1991-2020） | 几乎整个西欧和中欧 |
| 1979 年以来最暖 6 月 | 法国西北部、英格兰和威尔士大部、西班牙中北部 |
| 冷异常 | 仅欧洲最东端（俄罗斯西部、土耳其） |

**对应你的图应看到**：6 月 Tmax 异常核心在法国—西班牙北部—比荷卢—德国，向中欧
延伸；6 月 Tmin 同样显著甚至更极端（对应"夜间高温"：法国夜间为 1947 年以来最热、
维也纳某站夜间最低 27.3°C、斯洛伐克 Bratislava 最低 26.3°C、荷兰 De Bilt 夜间纪录等）。

## 6. 论文后续分析建议（热浪 + 夜间高温）

1. **热带夜（tropical nights）**：统计 2026 年 6 月欧洲 Tmin ≥ 20°C 的夜数及其
   1979-2026 百分位——这是"夜间高温"最直接的指标，WMO/WHO 明确指出评估热浪
   健康影响时 Tmin 往往比 Tmax 更有说服力。
2. **热浪日数与累积强度**：逐日 Tmax/Tmin 超 90 百分位（15 天滑动窗口气候态）的
   日数、超阈值温度之和（HWMId 等指标），弥补月平均对短时事件的稀释。
3. **趋势与归因**：对 1979-2026 逐月 Tmax/Tmin 做趋势分析（Sen 斜率/Mann-Kendall），
   讨论 2026 年事件在趋势背景下的"额外"极端性；可引用 WWA 归因结论
   （该热浪为该区域"有记录以来最严重"，气温偏高 5-12°C）。
4. **环流机制**：结合 500 hPa 位势高度异常（热穹顶）、海温（地中海西部海洋热浪、
   全球最高 6 月 SST）讨论事件的环流背景，提升论文层次。
5. **与观测对比**：ERA5 vs 站点（如 ECA&D）的 Tmax/Tmin 偏差评估。
